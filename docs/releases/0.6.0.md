# CodexMeter 0.6.0

- Add a Focus menu bar indicator, quick overview and resizable native workspace with persistent navigation.
- Add independent Cursor allowance and DeepSeek Harness local-session views alongside Codex. Each source retains its own data scope and unavailable states.
- Separate Codex account history from local daily estimates; retain the optional individual menu bar items and saved display preferences.
- Collect hardware details on demand and improve local log cursor retention and chart selection behavior.

Cursor uses its existing sign-in for read-only usage requests. DeepSeek Harness reads supported local checkpoints; its cumulative totals are not a daily or billing figure.

## Install or update

```sh
brew tap spider-man-peter-park/codexmeter https://github.com/spider-man-peter-park/CodexMeter
brew update
brew upgrade --cask spider-man-peter-park/codexmeter/codexmeter
```

For a first installation, use `brew install --cask spider-man-peter-park/codexmeter/codexmeter`. Requires macOS 14 or later. The prebuilt archive targets Apple Silicon; Intel users can build from source. The application is ad-hoc signed and is not notarized.
