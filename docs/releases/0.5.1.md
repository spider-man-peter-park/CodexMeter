# CodexMeter 0.5.1

- Fix sustained memory growth in CPU, GPU and RAM history charts by reusing fixed relative time-axis labels and retaining only bounded scalar chart points.
- Preserve actual sample-time selection, missing-reading gaps and accessible timestamps.
- Improve symmetric spacing around quota countdown dots while keeping menu bar widths fixed as readings change.
- Add an opt-in real-window memory regression test and document how to reproduce it.

In a matched 4,000-update rendering test, the repaired RAM chart remained at 33.5–35.4 MiB after warmup, with one history array and six measurable axis labels. CPU/GPU stress tests also passed. These accelerated synthetic updates are separate from normal-use elapsed-time monitoring and are not an account-wide or hardware-independent memory guarantee.

## Install or update

```sh
brew tap spider-man-peter-park/codexmeter https://github.com/spider-man-peter-park/CodexMeter
brew update
brew upgrade --cask spider-man-peter-park/codexmeter/codexmeter
```

For a first installation, use `brew install --cask spider-man-peter-park/codexmeter/codexmeter`.

Requires macOS 14 or later. The prebuilt archive is for Apple Silicon; Intel users can build from source. The app is ad-hoc signed, as in previous releases.
