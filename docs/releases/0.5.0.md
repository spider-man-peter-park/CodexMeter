# CodexMeter 0.5.0

- Add independent CPU, GPU and RAM menu bar items, plus one stacked upload/download item.
- Open the matching detail module from each menu bar item. Details expand fully and resize to their content.
- Add CPU core/load/process statistics; RAM pressure, composition, swap and process statistics; supported GPU telemetry/hardware; and network upload/download rates by process.
- Add separate icon, label and label-position controls for CPU/GPU/RAM, and an optional tok label for today's tokens.
- Keep menu widths fixed as readings change, tighten TPS spacing, center RAM labels over numeric digits, and center quota dot separators.
- Remove cached-quota asterisks and the Detail panel layout settings category. Existing navigation preferences remain intact.

System readings stay local and in memory. Hardware telemetry and protected process statistics can be unavailable; no estimated GPU process data or traffic contents are collected. RAM details use binary units; network rates use decimal bytes per second. Process traffic can differ from physical-interface totals when VPN forwarding is involved.

## Install or update

```sh
brew tap spider-man-peter-park/codexmeter https://github.com/spider-man-peter-park/CodexMeter
brew update
brew upgrade --cask spider-man-peter-park/codexmeter/codexmeter
```

For a first installation, use `brew install --cask spider-man-peter-park/codexmeter/codexmeter`.

Requires macOS 14 or later. The prebuilt archive is for Apple Silicon; Intel users can build from source. The app is ad-hoc signed, as in previous releases.
